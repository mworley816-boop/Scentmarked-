# Production defaults and identities

Verified against production Supabase on 2026-10-03. Recovery reference only.

## Identity columns

- affiliate_clicks.id — bigint GENERATED BY DEFAULT AS IDENTITY
- contact_messages.id — bigint GENERATED BY DEFAULT AS IDENTITY
- perfume_affiliate_offers.id — bigint GENERATED BY DEFAULT AS IDENTITY
- perfume_sources.id — bigint GENERATED BY DEFAULT AS IDENTITY
- recommendation_history.id — bigint GENERATED ALWAYS AS IDENTITY
- site_content.id — bigint GENERATED BY DEFAULT AS IDENTITY

## UUID defaults

The following IDs default to `gen_random_uuid()`: accords.id, brands.id, comparison_votes.id, notes.id, perfumes.id, ratings.id, scent_relationships.id.

## Timestamp defaults

`now()` is the production default on applicable created/updated/viewed/checked/clicked timestamp columns, including affiliate_clicks.clicked_at; brands.created_at; collection_items.created_at; comparison_votes.created_at; contact_messages.created_at; perfume_affiliate_offers.created_at/updated_at; perfume_image_provenance.checked_at/created_at/updated_at; perfume_sources.checked_at; perfumes.created_at/updated_at; profiles.created_at; ratings.created_at; recently_viewed_perfumes.viewed_at; recommendation_feedback.created_at/updated_at; recommendation_history.created_at; saved_comparisons.created_at; scent_relationships.created_at; site_content.created_at/updated_at.
